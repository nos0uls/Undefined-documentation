# Undefscene: Интерфейс

## Экран редактора

Экран делится на три основные зоны:

1. **Левая панель** — палитра нод **Actions** (перетаскивайте на холст) и **Bookmarks**
2. **Центральный холст** — рабочая область с нодами и связями
3. **Правая панель** — **Text** (Yarn Preview) и **Inspector** (настройка выбранной ноды)
4. **Нижняя панель** — **Logs / Ошибки** (валидация графа)

Панели Notes, Templates и Runtime JSON скрыты по умолчанию и открываются через меню **Panels** на верхней панели. Кнопки Undo / Redo находятся справа в верхней панели.

Боковые панели (docks) можно сворачивать кликом по иконке стрелки. В свернутом состоянии панель превращается в узкую полосу с кнопкой раскрытия. Отдельный **Zen Mode** (F12) скрывает все доки сразу, оставляя только холст.

## Управление на холсте

| Действие | Как |
|----------|-----|
| Создать ноду | Средняя кнопка мыши по пустому месту или кнопка **+** на холсте (создаёт Dialogue) |
| Добавить ноду из палитры | Перетащите из левой панели на холст или кликните по пункту палитры |
| Переместиться по холсту | Правая кнопка мыши + движение |
| Выделить несколько нод | Зажать левую кнопку и протянуть |
| Выбрать ноду/ребро | Клик левой кнопкой |
| Удалить ноду/ребро | Правый клик по элементу (удаляет сразу, без меню) или Delete для выделенных |
| Соединить ноды | Потянуть от handle одной ноды к другой |
| Задать задержку на ребре | Двойной клик по линии между нодами |
| Условие на ребре | Выбрать ребро → включить Condition в Inspector |

## Inspector

Когда вы выбираете ноду, в правой панели появляются её параметры. Заполните обязательные поля — без них экспорт покажет предупреждение.

Для некоторых нод Inspector показывает дополнительные возможности:

- **Dialogue** — панель Text с Yarn Preview: список нод из `.yarn` файла и текст выбранного блока
- **Follow Path** — Path Preview: форма траектории и анимированный маркер движения

## Панели (Panels)

### Логи / Ошибки (Logs)

Панель непрерывной валидации графа. Отображает ошибки, предупреждения и советы.

- **Error** — блокирует экспорт (критические ошибки)
- **Warn** — не блокирует, но важно исправить
- **Tip** — рекомендация по оптимизации

Клик по сообщению фокусирует холст на проблемной ноде.

### Заметки (Notes)

Заметки режиссёра на холсте. Можно прикреплять к нодам или оставлять свободными. Не экспортируются в игру.

| Категория | Цвет |
|-----------|------|
| acting | синий |
| camera | фиолетовый |
| sound | зелёный |
| todo | янтарный |
| warning | красный |

### Закладки (Bookmarks)

Список всех нод графа для быстрой навигации. Клик по элементу выделяет ноду и центрирует на ней холст.

### Шаблоны (Templates)

Сохранение и вставка фрагментов графа. Выделите несколько нод → **Save Selection**, затем вставьте шаблон в любую сцену кнопкой **Insert**. Панель скрыта по умолчанию — откройте её через меню **Panels**.

### Runtime JSON

Просмотр JSON-экспорта катсцены в реальном времени. Полезно для отладки формата, который получает движок.

## Visual Editing

**Visual Editing** — отдельное окно с фоном комнаты. Помогает расставить актёров и нарисовать путь движения, видя реальную геометрию комнаты.

Открывается через **View → Visual Editing** (требуется открытый проект `.yyp`). Это отдельное системное окно — оно отображается в Alt+Tab отдельно от редактора. Подробности — в разделе [Room Visual Editor](room-visual-editor.md).

### Инструменты Visual Editing

| Инструмент | Что делает |
|-----------|-----------|
| Pencil (B) | Рисует путь по точкам (кликайте на фоне) |
| Eraser (G) | Удаляет точки пути |
| Clear Path | Удаляет весь путь |
| Import Path (Ctrl+E) | Сохраняет нарисованный путь в Follow Path ноду |
| Select | Выделяет маркер актёра для перетаскивания |
| Place Selected Actor | Ставит актёра на позицию |
| Import Actors | Сохраняет позиции актёров в существующие Actor Create ноды |
| Play | Анимирует актёра вдоль пути (превью — граф не изменяет) |

### Клавиши-модификаторы

- **Shift** — привязка к горизонтали/вертикали
- Привязка точек пути к сетке 20 px включается чекбоксом **Snap to Grid** в секции Path Tools (смещение сетки настраивается полями Grid Offset X/Y)

!!! tip "Play — это только превью"
    Кнопка Play показывает, как актёр будет двигаться, но **не записывает** результат в граф. Для сохранения используйте Import Path / Import Actors.

## Preferences

Окно настроек: **File → Preferences...** (или Ctrl+P).

### General

- **Language** — `English` или `Русский`. Смена языка применяется мгновенно во всех окнах редактора.
- **Theme** — тема интерфейса. Изменение темы синхронизируется между основным редактором и окном Visual Editing.
- **Accent Color** — цвет акцентов. Синхронизируется глобально.

### Canvas

- **Mini Map Node Threshold** — числовой порог отключения миникарты (см. раздел [Mini Map](#mini-map) ниже)
- **Zoom Speed** — скорость зума колесом мыши
- **Grid Size** — шаг фоновой сетки (визуальный, не влияет на расстояние между нодами)

### Background

Можно поставить свою картинку на фон холста. Настройки: привязка (к холсту или к экрану), режим (Stretch / Cover), прозрачность 0–100%.

### Auto-save

- Вкл/выкл автосохранение
- Интервал автосохранения (1–120 минут, по умолчанию 10)
- Для сохранённых сцен — ротация backup-файлов `<имя>.autosave-N` рядом с основной сценой (до 5 копий)
- Для новых несохранённых сцен — файл `autosave-<дата>.usc.json` в служебной папке приложения

### Keyboard Shortcuts

Список горячих клавиш с возможностью переназначить. Переназначение реально действует для действий Toggle Inspector, Zen Mode и Toggle All Docks; остальные сочетания в редакторе заданы жёстко (см. таблицу ниже).

## Горячие клавиши

Часть сочетаний можно переназначить в **File → Preferences → Keyboard Shortcuts** (Toggle Inspector, Zen Mode, Toggle All Docks), остальные заданы жёстко. Действующие сочетания:

| Действие | Сочетание | Описание |
|----------|-----------|----------|
| Undo | `Ctrl+Z` | Отменить последнее действие |
| Redo | `Ctrl+Y` или `Ctrl+Shift+Z` | Повторить отменённое действие |
| Save | `Ctrl+S` | Сохранить сцену |
| New Scene | `Ctrl+N` | Создать новую сцену |
| Open Scene | `Ctrl+O` | Открыть сцену |
| Export | `Ctrl+E` | Экспорт в игру |
| Preferences | `Ctrl+P` | Открыть настройки |
| Select All | `Ctrl+A` | Выделить все ноды |
| Copy / Cut / Paste | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Работа с выделенными нодами |
| Delete | `Delete` | Удалить выделенные ноды и рёбра |
| Toggle Inspector | `Ctrl+Shift+I` | Показать/скрыть правую панель |
| Toggle All Docks | `Ctrl+Alt+D` | Свернуть/развернуть все панели |
| Fit View | `Space` или `Ctrl+0` | Вписать граф в экран |
| Zen Mode | `F12` (F11 в dev-режиме) | Скрыть все панели, оставить только холст |

!!! tip "Русская раскладка"
    Сочетания клавиш работают независимо от текущего языка ввода.

## Mini Map

Миникарта в углу холста показывает обзор всего графа. Настройка **Mini Map Node Threshold** управляет порогом отключения:

- `0` — миникарта выключена.
- `-1` — включена всегда.
- `> 0` — скрыта, если нод больше указанного значения.

По умолчанию порог равен `500`.

## Docking

Боковые панели можно прикреплять к левому, правому и нижнему краю, перетаскивая их за заголовок. При перетаскивании появляется превью зоны докинга. Чтобы вернуть панель, кликните по иконке стрелки на её заголовке.

- **Развернуть/свернуть** — стрелка на заголовке панели.
- **Zen Mode** — скрывает все панели, освобождая место для холста.
- **Reset Layout** — в меню **View** возвращает расположение панелей по умолчанию.

## Auto-update

Редактор проверяет обновления автоматически при запуске. В уведомлении (toast) отображается доступная версия и кнопка установки. Для portable-версии редактор только сообщает о новой версии, но не устанавливает её самостоятельно.

Ручная проверка: **Help → Check for Updates**.

## Welcome Setup

При первом запуске открывается экран приветствия, где можно выбрать язык, тему и акцентный цвет. Настройки применяются ко всем окнам редактора. Экран приветствия можно пропустить клавишей `Esc`.

После приветствия доступен интерактивный тур: **Help → Tutorial**. Он проводит по меню, палитре нод, холсту, инспектору и логам. Тур можно пройти повторно через тот же пункт меню.

## Toast-уведомления

Всплывающие уведомления в углу окна сообщают о ключевых событиях:

- `Exported` — успешный экспорт.
- `Update Available` — найдена новая версия.
- `Screenshot Copied` — скриншот скопирован в буфер обмена.
- `Log Copied` — лог скопирован в буфер обмена.

## Продвинутые инструменты

Технические инструменты спрятаны в **Help → Advanced**:

- **Show Runtime JSON** — открыть панель просмотра JSON-экспорта (полезно для отладки)
- **Open DevTools** — инструменты разработчика браузера
- **Disable Hardware Acceleration** — если редактор тормозит
- **Choose Screenshot Output Folder** — папка со скриншотами комнат для Visual Editing
- **Cleanup Dev Data** — сброс служебных данных разработки
- **Reset Severity Overrides** — сброс переопределений уровня сообщений валидации
