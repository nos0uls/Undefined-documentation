# Undefscene: Workflow

Процесс создания катсцены от подготовки до интеграции в игру.

## 1. Подготовка
1. Запустите редактор.
2. Подключите проект GameMaker: **Open Project** → выберите файл `.yyp`. Это активирует автозаполнение имен ресурсов.

## 2. Создание сцены
Нажмите **New Scene**. На холсте появится стартовая нода `Start`.

## 3. Построение графа
- Перетаскивайте ноды из левой палитры.
- Соединяйте выходы (справа) со входами (слева).
- Типовая структура: `Start` → `Actor Create` → `Move` → `Dialogue` → `End`.

## 4. Настройка параметров
Выберите ноду для редактирования свойств в **Inspector** (правая панель).

!!! tip "Задержки"
    Для пауз между действиями используйте двойной клик по ребру (линии связи) вместо отдельной ноды `Wait`.

## 5. Проверка и экспорт
1. Проверьте панель **Логи / Ошибки** (Logs / Warnings). Исправьте ошибки (пустые поля, недостижимые ноды).
2. **Save** (`.usc.json`): сохранение проекта для редактирования.
3. **Export to Game** («Экспорт в игру», `.json`): генерация файла для игры в `datafiles/cutscenes/`.

## 6. Вызов в коде
```gml
var _mgr = cutscene_load_json("cutscenes/my_scene.json");
_mgr.start_cutscene();
```

---

## Советы

- Сначала откройте `.yyp`, потом настраивайте параметры: так работает автокомплит
- Для сложных маршрутов используйте **Visual Editing**, чтобы рисовать путь на фоне комнаты
- Для Dialogue-нод проверяйте текст через **Yarn Preview** в панели Text
- Перед экспортом всегда проверяйте панель **Логи / Ошибки**
