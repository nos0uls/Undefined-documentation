# Undefscene: Глоссарий

Краткие определения терминов, которые встречаются в документации.

| Термин | Определение |
|--------|------------|
| **Нода (Node)** | Блок на холсте: одно действие в катсцене (движение, диалог, камера и т.д.) |
| **Ребро (Edge)** | Линия между нодами: переход от одного действия к следующему |
| **Inspector** | Правая панель, где настраиваются параметры выбранной ноды |
| **Target** | Цель действия: ключ актёра (например, `npc_guide`), `player`, `player_body` или имя объекта проекта |
| **Key** | Уникальное имя актёра. Задаётся в Actor Create, используется в других нодах как Target |
| **Actor** | Персонаж или объект на сцене катсцены. Создаётся через Actor Create |
| **Yarn** | Формат диалоговых файлов (`.yarn`). Используется движком Chatterbox |
| **.yyp** | Файл проекта GameMaker. Открытие `.yyp` в редакторе включает автокомплит и проверки |
| **.usc.json** | Рабочий формат редактора. Хранит граф, позиции нод и заметки (раскладка панелей сохраняется отдельно в настройках приложения) |
| **Engine .json** | Файл для игры. Создаётся через Export to Game |
| **Export to Game** | Команда экспорта катсцены в формат, который игра может прочитать (меню File) |
| **Visual Editing** | Отдельное окно с фоном комнаты для расстановки актёров и рисования путей |
| **Yarn Preview** | Панель с текстом диалога из `.yarn` файла: можно прочитать, не запуская игру |
| **Path Preview** | Превью траектории в Inspector для Follow Path ноды |
| **Edge Condition** | Условие на ребре: переход произойдёт только если условие истинно |
| **Wait on Edge** | Задержка на ребре: пауза перед переходом к следующей ноде |
| **Parallel** | Параллельное выполнение: несколько действий одновременно |
| **Branch** | Ветвление по результату функции: разные пути в зависимости от условия |
| **Branch Flag** | Ветвление по значению глобального флага `global.flag` |
| **Mark Node** | Именованная метка в графе: цель перехода для `GoTo Node` |
| **GoTo Node** | Переход выполнения сценария к метке или имени ноды |
| **Easing** | Тип плавности анимации: `linear`, `ease_in`, `ease_out`, `ease_in_out` |
| **Sprite** | Картинка-спрайт из проекта GameMaker |
| **Depth** | Слой глубины. Меньше значение = ближе к камере |
| **Facing** | Направление, куда смотрит актёр: left, right, up, down |
| **Emote** | Маленькая картинка над актёром (восклицательный знак, сердечки и т.п.) |
| **Tween** | Плавное изменение свойства со временем (например, прозрачности) |
| **SFX** | Звуковой эффект (Sound Effect) |
| **Fade In / Fade Out** | Плавное появление / затемнение экрана |
| **Instant Mode** | Режим, где все действия выполняются мгновенно (для отладки) |
| **Halt** | Остановка актёра и блокировка дальнейшего выполнения |
| **Autosave** | Автоматическое сохранение сцены через заданный интервал |
| **Attach To Target** | Привязка актёра к другому объекту (следование за родителем) |
| **Detach** | Отсоединение актёра от родительского объекта |
| **Checkpoint** | Сохранение состояния катсцены для последующего восстановления |
| **Restore State** | Восстановление ранее сохранённого состояния катсцены |
| **Schedule Action** | Отложенное выполнение действия через заданное время |
| **Partial Control** | Режим частичного контроля: игрок может двигаться или взаимодействовать во время катсцены |
| **Wait Interact** | Ожидание взаимодействия игрока с объектом |
| **Wait Talk** | Вариант ноды `Wait for Dialogue`. В экспортируемом JSON записывается как `waittalk`; игра при загрузке приводит его к `wait_for_dialogue` |
| **Set Portrait** | Установка эмоции диалогового портрета |
| **Dialogue Control** | Управление поведением диалогового окна (skip, auto-advance, stay open) |
| **Set Dialogue Speed** | Скорость печати текста в диалоге |
| **Wait Typing** | Ожидание завершения анимации печати текста |
| **Clear Dialogue** | Принудительная очистка диалогового окна |
| **Template Library** | Библиотека шаблонов графа для быстрого переиспользования |
| **Bookmarks** | Закладки на ноды для быстрой навигации |
| **Notes** | Заметки режиссёра на холсте (editor-only) |
| **Runtime JSON** | Панель с сырым JSON-состоянием сцены (ноды, рёбра, позиции) в реальном времени |
