# Room Visual Editor (RVE)

Визуальный редактор комнат для расстановки актёров и рисования путей поверх скриншота игровой локации.

## Обзор

*Room Visual Editor* (RVE) открывается из главного окна Undefscene и показывает фон выбранной комнаты. RVE нужен для двух задач:

- Расставить актёров по координатам комнаты и импортировать их позиции в ноды `Actor Create`.
- Нарисовать траекторию движения и импортировать точки в ноду `Follow Path`.

Окно работает независимо от основного редактора: это отдельное системное окно, видимое в Alt+Tab.

## Как открыть RVE

1. Подключите проект GameMaker через **File → Open Project (.yyp)**: без проекта список комнат и скриншотов будет пуст.
2. Откройте сцену или создайте новую.
3. Выберите в меню **View → Visual Editing**.
4. В открывшемся окне выберите комнату в выпадающем списке **Комната**: он с поиском и показывает только комнаты, для которых найдены скриншоты.

Скриншоты ищутся в настроенной папке вывода скриншотов, в папке скриншотов проекта и в `<папка проекта>/screenshots`. Если скриншотов не найдено ни для одной комнаты, список будет пуст с сообщением *«Нет комнат со скриншотами»*.

## Расстановка актёров

1. На панели **Актёры** выберите актёра из выпадающего списка. Список строится по нодам `Actor Create` открытого графа; если таких нод нет, доступны предварительные маркеры выбранной цели и `player` (они нужны только для предпросмотра и не импортируются).
2. Нажмите **Разместить актёра**: курсор перейдёт в режим размещения.
3. Кликните по фону в точке, где должен стоять персонаж.
4. Повторите для всех нужных позиций.
5. Нажмите **Импорт актёров**: координаты попадут в параметры `x`/`y` нод `Actor Create`, которые соответствуют размещённым маркерам (сопоставление по идентификатору ноды; обновляются все совпавшие ноды).

!!! tip "Режим выбора"
    Чтобы передвинуть уже размещённого актёра, переключитесь в режим **Выбор** и перетащите маркер.

## Рисование путей

1. Выберите инструмент **Карандаш** на панели **Путь**.
2. Кликайте по фону, чтобы добавлять точки траектории.
3. Для прямых линий удерживайте **Shift**.
4. Чтобы стереть точку, переключитесь на **Ластик** (горячая клавиша `G`).
5. Нажмите **Импорт пути**: точки сохранятся в поле `points` ноды `Follow Path` (см. раздел [Импорт координат](#_4) ниже).

Инструменты пути:

| Кнопка | Действие |
|--------|----------|
| **Карандаш** | Добавить точку кликом (`B`) |
| **Ластик** | Удалить точку (`G`) |
| **Очистить путь** | Удалить все точки |
| **Импорт пути** | Записать точки в ноду `Follow Path` (`Ctrl+E`) |

Отмена и повтор последних точек черновика пути: через `Ctrl+Z` / `Ctrl+Y` (или `Ctrl+Shift+Z`).

## Импорт координат

RVE работает в координатах игрового мира, поэтому импортированные значения можно использовать в нодах напрямую, без ручного пересчёта.

- **Импорт актёров** обновляет поля `x` и `y` существующих нод `Actor Create`, соответствующих размещённым маркерам. Новые ноды не создаются; виртуальные маркеры (когда в графе нет `Actor Create`) не импортируются.
- **Импорт пути** работает по выбранной ноде в основном редакторе: если нода выделена, редактор с подтверждением **заменяет её** на `Follow Path` (сохраняя `target`, `speed_px_sec`, `collision`); если нода не выделена, с подтверждением создаётся новая нода `Follow Path`. Точки записываются в массив `points` с округлением до целых.

## Клавиши и масштабирование

| Клавиша | Действие |
|---------|----------|
| `B` | Карандаш |
| `G` | Ластик |
| `Ctrl+E` | Импорт пути |
| `Ctrl+Z` / `Ctrl+Y` | Отмена / повтор правок черновика пути |
| `Shift` | Прямая линия при рисовании |
| `Esc` | Закрыть окно редактора |
| Колесо мыши | Масштаб (вокруг курсора, диапазон 0.1–8×) |
| Левая кнопка мыши по пустому месту | Перемещение вида (когда не активен инструмент пути/актёра) |
| **Приблизить / Отдалить** | Кнопки на панели (шаг ×1.25) |
| **По размеру** | Вписать комнату в окно |
| **Сброс** | Вернуть масштаб 1× и начальный сдвиг |

Секция **Path Tools** содержит чекбоксы **Show Grid** (отображение сетки, шаг 20 px) и **Snap to Grid** (привязка точек пути к сетке), а также поля **Grid Offset X/Y**: смещение сетки (диапазон −200…200), если тайлы комнаты начинаются не с `(0, 0)`. Там же настраивается **Path Size Multiplier** (0.5–4): масштаб отображения пути.

## Troubleshooting

!!! warning "Скриншот не загружается"
    Проверьте папку скриншотов в настройках (**File → Preferences → Editor → Screenshot Output Folder**) или через **Help → Advanced → Choose Screenshot Output Folder**. Если папка пустая, сделайте скриншоты в GameMaker или укажите путь к существующим. Также скриншоты подхватываются из `<папка проекта>/screenshots`.

!!! warning "Импорт актёров неактивен"
    Кнопка активна только когда размещён хотя бы один реальный маркер, то есть когда в графе есть ноды `Actor Create`. Маркеры-предпросмотра для выбранной цели и `player` не импортируются.

!!! warning "Путь не импортируется"
    Нужна хотя бы одна точка в черновике пути. При импорте выделенная в основном редакторе нода будет заменена на `Follow Path`; без выделения будет создана новая нода. Оба действия требуют подтверждения.
