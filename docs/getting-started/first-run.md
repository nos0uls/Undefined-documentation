# Первый Запуск (First Run)

Инструкции по первичному запуску проекта и описание ожидаемого поведения.

## Запуск из IDE

1.  В GameMaker Studio 2 нажмите `F5` или кнопку **Play**.
2.  Начнется компиляция.
3.  Откроется окно игры.

## Ожидаемое поведение

1.  **Инициализация**: Кратковременный черный экран в `rm_init`.
2.  **Главное Меню**: Переход на титульный экран.
3.  **Музыка**: Автоматический запуск фонового трека меню.

## Управление в меню

- **Стрелки / WASD**: Навигация.
- **Z / Enter / Пробел**: Подтверждение.
- **X / Esc**: Назад.

## Решение проблем

Если игра не запускается:
- Проверьте вкладку `Output` в IDE на наличие ошибок GML.
- При повреждении `game_state.dat` удалите файл (будет создан новый с дефолтными значениями).
