# Настройка окружения (Setup Guide)

Подготовка рабочего окружения для разработки **Undefinedtale-888**.

## 1. GameMaker Studio 2
Проект разработан на версии **GMS 2023+**.
1. Скачайте инсталлятор с [официального сайта](https://gamemaker.io/en/get), либо из Steam.
2. (Опционально) Авторизуйтесь под своей учетной записью.

## 2. Зависимости
Все необходимые библиотеки уже встроены в проект:
- **[Scribble](https://github.com/JujuAdams/Scribble)**: движок рендеринга текста.
- **[Chatterbox](https://github.com/JujuAdams/Chatterbox)**: рантайм для диалогов Yarn.

## 3. Запуск проекта
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/n0souls/Undefinedtale-888.git
   ```
2. Откройте `.yyp` файл в GMS2.
3. Нажмите `F5` для компиляции и запуска.

## 4. Стандарты разработки
- **JSDoc**: обязательное описание функций (`/// @desc`, `/// @param`).
- **Именование**:
    - `obj_Name` (объекты)
    - `spr_Name` (спрайты)
    - `scr_camelCase` (скрипты)
    - `snake_case` (переменные)

## 5. Документация

Документация сайта построена на **MkDocs Material** и развёрнута на GitHub Pages.

### Редактирование

1. Откройте нужный `.md` файл в папке `docs/`.
2. Внесите правки, используя [синтаксис Markdown](syntax.md).
3. При добавлении новой страницы — зарегистрируйте её в `nav` секции `mkdocs.yml`.

### Коммиты и отправка

```bash
git add docs/your-file.md mkdocs.yml
git commit -m "docs: описание изменений"
git push
```

После push в `main` GitHub Actions автоматически соберёт и опубликует сайт. Сборка проходит в `--strict` режиме — любые предупреждения ломают билд.

### Редактирование через GitHub UI

На любой странице сайта нажмите кнопку-карандаш вверху справа. Это откроет редактор на GitHub, где можно внести правки и создать коммит напрямую.
