# Синтаксис Markdown

Правила оформления документации и использования расширений MkDocs Material.

## Основы Markdown

Для написания страниц используется стандартный синтаксис с расширениями PyMdown.

### 1. Заголовки и переносы
- Заголовки: `# H1`, `## H2`, `### H3`.
- Перенос строки: два пробела в конце строки или пустая строка между абзацами.

### 2. Форматирование
- **Жирный**: `**текст**`.
- *Курсив*: `*текст*`.
- Списки: `-` для маркированных, `1.` для нумерованных.

### 3. Код
- Инлайн-код: `` `code` ``.
- Блоки кода с указанием языка:
```gml
// Пример GML
if (keyboard_check(vk_right)) x += 4;
```

### 4. Ссылки и Изображения
- Ссылки: `[Текст](url)`.
- Внутренние ссылки: `[Текст](../folder/file.md)`.
- Изображения: `![Описание](../images/file.png)`.

### 5. Admonitions (Заметки)
Используйте для акцентирования внимания:

```markdown
!!! note "Заголовок"
    Текст заметки.

!!! warning "Внимание"
    Текст предупреждения.
```

### 6. Добавление страниц
1. Создайте `.md` файл в папке `docs/`.
2. Добавьте путь к файлу в раздел `nav` файла `mkdocs.yml`.
3. Соберите проект для проверки навигации.

## Структура страниц

- Все ресурсы хранятся в подпапках `docs/`.
- Новые разделы требуют создания папки и регистрации в `mkdocs.yml`.
- Для встраивания видео используйте стандартный `<iframe>` или расширение `superfences`.
