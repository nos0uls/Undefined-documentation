# Катсцены: Типовые проблемы

## Камера не двигается
**Причина**: Активирован `global.cutscene_camera_override`, блокирующий следование за игроком.
**Решение**: Добавьте экшен камеры `cutscene_camera_track` или `c_panobj`.

## Катсцена зависла
**Причина**: Один из экшенов не возвращает `true` в `update()`.
**Решение**: Проверьте Debug Overlay. Если счетчик `Wait` красный — этот шаг блокирует очередь. Часто это связано с ожиданием диалога, который не был запущен или завершен.

## Актёр не найден
**Причина**: Ошибка в строковом ключе `actor_map` или актёр еще не создан.
**Решение**: Используйте **instance id** вместо имен для критически важных действий. Проверьте логи на наличие предупреждений `resolve_target`.

## Игрок не может двигаться после катсцены
**Причина**: Досрочный выход из катсцены (ESC/X) не вызывал `cleanup()` для текущего action'а. `move_active` оставался `true`, блокируя `scr_player_movement`.
**Решение**: Обновите движок до версии, где `finish_cutscene()` очищает все action'ы. Если проблема возникла — перезайдите в комнату.

## Актёр созданный через `copy_from` рендерится неправильно
**Причина**: `ActionActorCreate` больше не копирует `depth` из источника — проект использует isometric sorting (`depth = -y`).
**Решение**: Убедитесь, что `par_depth` корректно обрабатывает `depth_mode` для нового актёра (по умолчанию `auto`).

## Объект не уничтожается через `destroy_entity`
**Причина**: `ActionDestroy` имеет защиту от уничтожения `obj_player`.
**Решение**: Для уничтожения игрока используйте отдельную логику (не рекомендуется в катсценах).

## `parallel` зацикливается или не завершается
**Причина**: `ActionParallel` не отслеживал завершённые вложенные экшены, вызывая повторный `update()` и `cleanup()`.
**Решение**: Runtime обновлён — каждая ветка `parallel` помечается как завершённая после первого возврата `true` из `update()`. Убедитесь, что вложенные экшены корректно возвращают `true` (например, `wait` с истёкшим таймером).

## Debug Overlay вызывает краш "Variable not set before reading it"
**Причина**: Рекурсивная локальная функция в `Draw_64` `obj_cutsceneManager` не инициализировалась до вызова.
**Решение**: Debug overlay переписан на итеративный обход стека. Обновите движок до версии с итеративным `__dbg_collect_active`.

## `cutscene_wait` работает слишком быстро/медленно
**Причина**: Путаница между секундами и кадрами.
**Решение**: Все GML-функции `wait` принимают время в **кадрах**. В JSON-файлах время указывается в **секундах**.
