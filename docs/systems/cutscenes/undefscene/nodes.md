# Справочник нод

Действия катсцены, представленные в виде блоков графа.

## Категории нод

| Категория | Цвет | Ноды |
|-----------|------|------|
| Поток | синий | Start, End, Wait |
| Движение | фиолетовый | Move, Follow Path, Set Position, Move Relative, Set Position Relative, Jump, Halt |
| Актёры | фиолетовый | Actor Create, Actor Destroy |
| Визуал | фиолетовый | Animate, Set Animation Frame, Set Facing, Set Depth, Auto Facing, Auto Walk, Flip, Spin, Shake Object, Set Visible, Emote, Set Emotion |
| Диалог | розовый | Dialogue, Wait for Dialogue |
| Камера | зелёный | Camera Pan, Camera Pan To Object, Camera Center, Camera Track, Camera Track Until Stop, Camera Shake, Tween, Tween Camera, Set Property, Fade In, Fade Out |
| Логика | оранжевый | Parallel Start, Parallel Join, Branch, Run Function, Instant Mode, Mark Node, Wait Until |
| Звук | бирюзовый | Play SFX, Play Music, Stop Music, Music Volume, Music Duck, Music Unduck, Music Pitch, Music Pause, Music Resume |

## Поток (Flow)

### Start
Точка входа. В графе должна быть одна нода Start без входящих связей.

### End
Точка завершения. В графе должна быть хотя бы одна нода End без исходящих связей.

### Wait
Задержка выполнения в секундах.

| Параметр | Описание |
|----------|----------|
| seconds | Длительность ожидания |

!!! tip "Wait на ребре"
    Используйте двойной клик по линии связи для установки задержки без отдельной ноды `Wait`.

## Движение (Movement)

### Move
Перемещение актёра со спрайтом ходьбы.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| x, y | Целевые координаты |
| speed_px_sec | Скорость в px/sec |
| collision | `true` — учитывать стены и препятствия |

### Set Position
Мгновенная телепортация без анимации.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| x, y | Новые координаты |

### Move Relative
Перемещение актёра на заданное смещение от текущей позиции со спрайтом ходьбы.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| dx | Смещение по X от текущей позиции |
| dy | Смещение по Y от текущей позиции |
| speed_px_sec | Скорость в px/sec |
| collision | `true` — учитывать стены и препятствия |

### Set Position Relative
Мгновенное смещение позиции актёра относительно текущей позиции без анимации.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| dx | Смещение по X от текущей позиции |
| dy | Смещение по Y от текущей позиции |

### Follow Path
Движение по маршруту из нескольких точек.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| points | Список точек `{ x, y }` |
| speed_px_sec | Скорость в px/sec |
| collision | `true` — учитывать стены и препятствия |
| autofacing | `true` — автоматически поворачивать актёра по направлению движения |

### Jump
Движение по дуге с заданной высотой.

| Параметр | Описание |
|----------|----------|
| target | Цель прыжка |
| x, y | Точка приземления |
| seconds | Длительность |
| height | Максимальная высота дуги |
| easing | `linear`, `ease_in`, `ease_out`, `ease_in_out` |

### Halt
Принудительная остановка всех действий актёра.
!!! warning "Блокировка"
    Halt блокирует очередь выполнения катсцены для данной ветки.

## Актёры (Actor)

### Actor Create
Создание нового инстанса на сцене.

| Параметр | Описание |
|----------|----------|
| actor_name | Уникальный ID для ссылок в других нодах |
| x, y | Позиция спавна |
| actor_sprite | Ассет спрайта или объекта |
| copy_target | Источник для копирования свойств (scale, depth) |

### Actor Destroy
Удаление инстанса из мира.

## Визуал (Visual)

### Animate
Смена текущего спрайта и скорости анимации.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| sprite | Новый ассет спрайта |
| image_index | Номер стартового кадра |
| image_speed | Множитель скорости анимации |

### Set Animation Frame
Установка конкретного кадра анимации без смены спрайта.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| image_index | Номер кадра |
| image_speed | Множитель скорости анимации |
| pause | `true` — приостановить анимацию на этом кадре |

### Set Facing
Установка направления взгляда.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| direction | `left`, `right`, `up` или `down` |

### Auto Facing
Управление автоматическим поворотом актёра при движении.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| enabled | `true` — включить `auto_face`, `false` — выключить |

### Auto Walk
Управление автоматической анимацией ходьбы актёра.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| enabled | `true` — включить `auto_walk`, `false` — выключить |

### Flip
Горизонтальное отражение актёра.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| flipped | `true` — смотреть влево через отрицательный `image_xscale` |

### Shake Object
Эффект дрожания актёра (удары, эмоции).

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| seconds | Длительность |
| magnitude | Общая сила смещения в пикселях |
| magnitude_x | Сила по X (переопределяет `magnitude`) |
| magnitude_y | Сила по Y (переопределяет `magnitude`) |
| decay | `true` — амплитуда затухает со временем |
| frequency | Частота тряски (кадров на цикл) |

### Emote
Отрисовка иконки эмоции над головой актёра.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| sprite | Спрайт иконки |
| seconds | Длительность отображения |
| offset_x, offset_y | Смещение относительно головы |
| scale | Масштаб иконки |
| wait | `true` — блокировать очередь до исчезновения эмоции |

### Set Emotion
Установка эмоционального состояния актёра.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| emotion | `default`, `neutral`, `angry`, `sad`, `scared`, `happy`, `confused` |
| apply_to_sprite | `true` — применить к спрайту актёра |
| apply_to_portrait | `true` — применить к диалоговому портрету |

## Диалог (Dialogue)

### Dialogue
Запуск текстового блока из Yarn-файла.

| Параметр | Описание |
|----------|----------|
| file | Путь к `.yarn` файлу |
| node | Имя стартового узла |

### Wait for Dialogue
Ожидание завершения текущего активного диалога.

| Параметр | Описание |
|----------|----------|
| dialogue_controller | Instance ref диалогового контроллера (опционально; пусто — активный textbox)

## Камера (Camera)

### Camera Pan
Плавное перемещение объектива в точку.

| Параметр | Описание |
|----------|----------|
| x, y | Целевые координаты |
| seconds | Длительность перемещения |

### Camera Pan To Object
Плавное перемещение объектива к актёру или игроку.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| seconds | Длительность перемещения |

### Camera Center
Мгновенная установка камеры в точку.

| Параметр | Описание |
|----------|----------|
| x, y | Координаты центра |

### Camera Track
Слежение за целью в течение заданного времени.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| seconds | Длительность слежения |
| offset_x | Смещение по X |
| offset_y | Смещение по Y |

### Camera Track Until Stop
Слежение за целью до тех пор, пока она не прекратит движение (пока `move_active` не станет `false`). Рекомендуется использовать в `Parallel` ветке вместе с нодами движения (`Move`, `Follow Path`).

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или `player` |
| offset_x | Смещение по X |
| offset_y | Смещение по Y |

### Camera Shake
Тряска камеры.

| Параметр | Описание |
|----------|----------|
| seconds | Длительность |
| magnitude | Общая сила смещения в пикселях |
| magnitude_x | Сила по X (переопределяет `magnitude`) |
| magnitude_y | Сила по Y (переопределяет `magnitude`) |
| decay | `true` — амплитуда затухает со временем |
| frequency | Частота тряски (кадров на цикл) |

### Tween
Плавная интерполяция числового свойства актёра.

| Параметр | Описание |
|----------|----------|
| kind | `instance` или `camera` |
| target | Ключ актёра или `player`; не нужен для `camera` |
| prop | Имя числового свойства |
| end_value | Конечное значение; при export становится `to_value` |
| start_value_override | Стартовое значение (опционально); при export становится `from_value` |
| duration_frames | Длительность в секундах |
| ease_name | `linear`, `ease_in`, `ease_out`, `ease_in_out` |

### Tween Camera
Плавная интерполяция свойства камеры.

| Параметр | Описание |
|----------|----------|
| property | `x`, `y`, `view_x`, `view_y`, `camera_x` или `camera_y` |
| to_value | Конечное значение |
| from_value | Стартовое значение |
| duration_frames | Длительность в секундах |
| ease_name | `linear`, `ease_in`, `ease_out`, `ease_in_out` |

### Set Property
Установка свойства актёра или камеры без tween.

| Параметр | Описание |
|----------|----------|
| kind | `instance` или `camera` |
| target | Ключ актёра или `player`; не нужен для `camera` |
| property | Имя свойства |
| value | Значение; JSON-строка парсится перед export |


### Fade In / Out
Управление общим затемнением экрана.

| Параметр | Описание |
|----------|----------|
| seconds | Длительность |

## Логика (Logic)

### Parallel Start / Join
Разветвление очереди на несколько параллельных потоков и их последующее слияние.

| Параметр | Описание |
|----------|----------|
| branches | Массив ID веток (editor-only) |
| joinId | ID связанной join-ноды (editor-only) |
| pairId | ID связанной start-ноды (editor-only, только для join) |

### Branch
Ветвление логики на основе глобальных переменных.

| Параметр | Описание |
|----------|----------|
| condition | Выражение условия (например, `global.flag["key"] == 1`) |

### Run Function
Вызов произвольной GML-функции с аргументами.

| Параметр | Описание |
|----------|----------|
| function | Имя GML-функции или скрипта |
| args | JSON-массив аргументов; при export становится `arguments` |

### Instant Mode
Режим мгновенного выполнения (0 кадров) всех последующих нод.

| Параметр | Описание |
|----------|----------|
| enabled | `true` — включить instant-режим, `false` — выключить |

### Mark Node
Создаёт именованную метку в очереди действий. Используется как цель для прыжков (`Jump`) или условий ожидания.

| Параметр | Описание |
|----------|----------|
| name | Уникальное имя метки |

!!! tip "Автоподстановка (Autocomplete)"
    Большинство строковых полей (ассеты спрайтов, Yarn‑файлы, имена нод, флаги и метки) поддерживают автоподстановку. Начните вводить текст, чтобы увидеть список доступных ресурсов из проекта. Выпадающий список автоматически подстраивается под тип поля.

### Set Flag
Установка значения глобального флага.

| Параметр | Описание |
|----------|----------|
| key | Имя флага (без `global.flag`) |
| value | Значение (число или строка) |

### Set Plot
Изменение основной сюжетной переменной `global.plot`.

| Параметр | Описание |
|----------|----------|
| value | Новое числовое значение сюжета |

### Spawn Entity
Создание игрового объекта или NPC во время сцены.

| Параметр | Описание |
|----------|----------|
| object | Ассет объекта из проекта |
| key | Опциональный ключ для ссылок в этой катсцене |
| x, y | Координаты спавна |
| depth | Глубина отрисовки |
| persistent | Если `true`, объект не удалится при смене комнаты |

### Destroy Entity
Удаление объекта или NPC.

| Параметр | Описание |
|----------|----------|
| target | Ключ актёра или ID инстанса |

### Partial Control
Переключение уровня контроля игрока. Позволяет ходить или взаимодействовать, пока сцена стоит на паузе.

| Параметр | Описание |
|----------|----------|
| control_type | `0`: нет контроля, `1`: движение + взаимодействие (whitelist), `2`: полный |
| whitelist | JSON-массив объектов для взаимодействия в типе `1` |

### Wait for Interact
Приостановка сцены до взаимодействия игрока с объектом.

| Параметр | Описание |
|----------|----------|
| target | Цель взаимодействия |
| timeout | Макс. время ожидания в секундах (0 = бесконечно) |
| timeout_action | Действие при таймауте: `continue` или `skip` |

### Wait Until
Ожидание выполнения условия или истечения таймаута.

| Параметр | Описание |
|----------|----------|
| condition_var | Имя проверяемой переменной или флага |
| condition_equals | Ожидаемое значение для сравнения |
| timeout_seconds | Максимальное время ожидания в секундах (0 = бесконечно) |

!!! note "Проверка условия"
    Нода опрашивает `condition_var` каждый кадр. Как только значение совпадает с `condition_equals`, выполнение продолжается. При `timeout_seconds` > 0 сцена продолжится по истечении времени даже если условие не выполнено.

## Звук (Audio)

### Play SFX
Воспроизведение звукового эффекта.

| Параметр | Описание |
|----------|----------|
| sound | Имя звукового ассета |
| volume | Громкость (0–1) |
| pitch | Скорость воспроизведения |

### Play Music
Воспроизведение фоновой музыки.

| Параметр | Описание |
|----------|----------|
| sound | Звуковой ассет (с поддержкой поиска) |
| volume | Громкость (0–1) |
| fade | Длительность fade-in в секундах |

!!! tip "Плавная смена трека"
    Если музыка уже играет, текущий трек плавно останавливается с заданным `fade`, а новый начинается с fade-in.

### Stop Music
Остановка фоновой музыки.

| Параметр | Описание |
|----------|----------|
| fade | Длительность fade-out в секундах |

### Music Volume
Изменение громкости фоновой музыки.

| Параметр | Описание |
|----------|----------|
| volume | Целевая громкость (0–1) |
| fade | Длительность плавного перехода в секундах |

### Music Duck
Временное снижение громкости музыки для приоритета голоса или эффектов.

| Параметр | Описание |
|----------|----------|
| multiplier | Множитель громкости (0–1) |
| fade | Длительность fade-out в секундах |

!!! tip "Комбинация с диалогом"
    Используйте `music_duck` перед нодой `Dialogue`, чтобы музыка затихала на время реплик.

### Music Unduck
Возврат громкости музыки к исходному уровню после `music_duck`.

| Параметр | Описание |
|----------|----------|
| fade | Длительность fade-in в секундах |

### Music Pitch
Изменение скорости воспроизведения фоновой музыки.

| Параметр | Описание |
|----------|----------|
| pitch | Множитель скорости, шаг 0.1, по умолчанию 1 |

!!! warning "Высокие значения"
    Значения `pitch` выше 1.5 могут привести к артефактам сжатия в зависимости от кодека исходного файла.

### Music Pause
Приостановка воспроизведения фоновой музыки. Позиция трека сохраняется для последующего `music_resume`.

### Music Resume
Возобновление воспроизведения фоновой музыки с места остановки.

## Мета (Meta)

### Director Note
Редактор-only заметка режиссёра. Не экспортируется в JSON и не влияет на runtime.

| Параметр | Описание |
|----------|----------|
| note_text | Текст заметки |
| category | Категория: `acting`, `camera`, `sound`, `todo`, `warning` |
| pinned | `true` — заметка закреплена |
