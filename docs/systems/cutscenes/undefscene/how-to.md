# How-to: Типовые задачи

Краткие инструкции для реализации часто встречающихся сценариев.

## Создание первой катсцены
1. **New Scene**: инициализация пустого графа.
2. **Start → Dialogue**: соедините стартовую ноду с блоком диалога.
3. **Настройка**: выберите файл и ноду в Inspector.
4. **Dialogue → End**: завершите цепочку.
5. **Export**: сохраните `.json` в `datafiles/cutscenes/`.

## Работа с диалогами
- Используйте ноду **Dialogue** для запуска текста.
- Читайте содержимое ноды во встроенном **Yarn Preview** (панель Text).
- Добавляйте **Wait for Dialogue**, если следующие действия должны начаться после закрытия окна.

## Движение по маршруту
1. **Actor Create**: создайте актёра с уникальным ключом.
2. **Follow Path**: выберите созданный ключ в `Target`.
3. **Visual Editing**: нарисуйте путь поверх фона комнаты.
4. **Import Path**: сохраните координаты в ноду.

## Управление камерой
- **Camera Pan**: плавный проезд в точку.
- **Camera Track**: фиксация объектива на актёре.
- **Camera Shake**: эффект дрожания (длительность в секундах).

## Параллельные действия
Используйте пару **Parallel Start** и **Parallel Join**. Все цепочки нод между ними будут выполняться одновременно.

## Условия перехода
- **Branch**: явное разветвление графа.
- **Edge Condition**: условие прямо на стрелке связи (двойной клик по ребру).

## Поворот актёра
- **Set Facing**: разовый поворот в сторону.
- **Auto Facing**: постоянное слежение взглядом за игроком.

## Звуковые эффекты
- **Play SFX**: мгновенный запуск звукового ассета. Настраивайте `Volume` и `Pitch` в Inspector.

## Управление музыкой в катсцене

1. Добавьте на граф ноду `Play Music` из категории **Звук**.
2. В Inspector выберите музыкальный ассет в поле `sound` и задайте `volume` (0–1).
3. Для плавного приглушения во время диалога добавьте ноду `Music Duck` перед блоком реплик.
4. Настройте `multiplier` (например, `0.3`) и `fade` — время перехода к приглушённой громкости.
5. После диалога добавьте `Music Unduck` для возврата полной громкости.
6. Для остановки в конце катсцены используйте `Stop Music` с нужным временем фейда в поле `fade`.

!!! tip " `Music Duck` или `Music Volume`?"
    `Music Duck` умножает текущую громкость на множитель, сохраняя настройки игрока.  
    `Music Volume` задаёт абсолютное значение. Для диалогов и катсцен предпочтительнее `Music Duck`.

## Относительное движение актёра

1. Выберите актёра, который уже создан нодой `Actor Create` или является `player`.
2. Добавьте ноду `Move Relative` из категории **Движение**.
3. В Inspector укажите `target` — ключ актёра.
4. Задайте смещение по осям: `dx` (по X) и `dy` (по Y). Положительные значения — вправо и вниз, отрицательные — влево и вверх.
5. Для мгновенной телепортации на смещение используйте `Set Position Relative` с теми же полями `target`, `dx`, `dy`.

## Ожидание условия

1. Добавьте на граф ноду `Wait Until` из категории **Логика**.
2. В Inspector укажите `condition_var` — имя глобальной переменной или флага (например, `global.plot`).
3. В поле `condition_equals` задайте значение, при котором выполнение продолжится.
4. При необходимости установите `timeout_seconds` — максимальное время ожидания. `0` означает бесконечное ожидание.
5. Подключите выход `Wait Until` к следующей ноде. Катсцена приостановится до тех пор, пока переменная не станет равной указанному значению.

## Привязка актёра к другому объекту

1. Создайте обоих актёров через `Actor Create`.
2. Добавьте ноду `Attach To Target` из категории **Актёры**.
3. В Inspector укажите `target_ref` — ключ актёра, который будет следовать, и `parent_ref` — ключ родительского актёра.
4. Настройте `offset_x` и `offset_y` для смещения.
5. Установите `follow_facing`, `follow_scale`, `follow_depth` по необходимости.
6. Для отсоединения используйте ноду `Detach`.

## Использование чекпоинтов

1. В нужный момент катсцены добавьте `Checkpoint State` из категории **Логика**.
2. Задайте `checkpoint_id` — уникальный идентификатор.
3. Выберите, что сохранять: актёров, игрока, камеру, музыку, глобальные переменные.
4. Для восстановления добавьте `Restore State` и укажите тот же `checkpoint_id`.

## Отложенные действия

1. Добавьте `Schedule Action` из категории **Логика**.
2. Задайте `delay_seconds` — время задержки.
3. Выберите `action_type` из списка поддерживаемых действий (`play_sfx`, `emote`, `flip` и др.).
4. В `action_params` введите параметры действия в формате JSON.
5. Установите `blocking` в `true`, если нужно дождаться завершения вложенного действия.

## Управление диалогом

1. Добавьте `Set Dialogue Speed` перед нодой `Dialogue` для изменения скорости печати.
2. Используйте `Dialogue Control` для запрета пропуска (`prevent_skip`), автоперехода (`auto_advance`) или удержания окна (`stay_open`).
3. `Set Portrait Next` / `Set Portrait Now` меняют эмоцию портрета актёра.
4. `Clear Dialogue` принудительно очищает окно.
5. `Wait Typing` приостанавливает катсцену до завершения анимации печати текущей реплики.

## Эмоции над персонажами

1. Добавьте ноду `Emote` (или `Show Emote`) из категории **Актёры**.
2. В Inspector выберите `target` — ключ актёра.
3. Укажите `sprite` — спрайт эмоции (например, `spr_emote_exclamation`).
4. Настройте `seconds` — длительность показа, `offset_x`/`offset_y` — смещение относительно актёра.
5. Установите `wait = true`, если катсцена должна дождаться окончания анимации эмоции.

## Прыжок актёра

1. Добавьте ноду `Jump` из категории **Движение**.
2. Укажите `target` — ключ актёра и целевые координаты `x`, `y`.
3. Настройте `seconds` — время прыжка, `height` — высота дуги (по умолчанию 16 px).
4. Выберите `easing` для контроля формы траектории (по умолчанию `linear`).

## Остановка движения

1. Добавьте ноду `Halt` из категории **Движение**.
2. Укажите `target` — ключ актёра, который нужно остановить.
3. Нода мгновенно сбрасывает скорость и флаги движения актёра.

## Fade In / Fade Out

1. Добавьте ноду `Fade In` или `Fade Out` из категории **Визуальные эффекты**.
2. Укажите `seconds` — длительность затухания.
3. При необходимости задайте `color` — цвет затемнения (по умолчанию чёрный).
4. `Fade In` убирает затемнение экрана; `Fade Out` — затемняет его.

## Работа в Room Visual Editor

1. Откройте **View → Visual Editing**.
2. Выберите комнату из выпадающего списка. Если список пуст — убедитесь, что открыт проект `.yyp`.
3. Для расстановки актёров: выберите актёра, нажмите **Разместить актёра**, кликните на фон, затем **Импорт актёров**.
4. Для пути: выберите **Карандаш**, кликайте по точкам, затем **Импорт пути** для выбранной ноды `Follow Path`.
5. Чтобы стереть точку, переключитесь на **Ластик** (`G`).

!!! tip "Прямые линии"
    Удерживайте `Shift` при рисовании, чтобы получить прямую линию по горизонтали или вертикали.

## Шаблоны (Templates)

1. Выделите несколько нод на холсте.
2. В панели **Template Library** нажмите **Save as Template** и дайте имя.
3. Чтобы вставить шаблон, выберите его в библиотеке и нажмите **Insert**.
4. Шаблоны хранятся локально и доступны в любой сцене.

## Закладки (Bookmarks)

1. В панели **Bookmarks** нажмите **Add Bookmark** для выбранной ноды.
2. Двойной клик по закладке центрирует холст на ноде.
3. Закладки помогают быстро перемещаться между ключевыми моментами длинной сцены.

## Заметки (Notes)

1. В панели **Notes** нажмите **+**, чтобы добавить заметку режиссёра.
2. Выберите категорию: acting, camera, sound, todo или warning.
3. Закрепите важные заметки, чтобы они оставались наверху списка.
4. Привяжите заметку к выбранной ноде через кнопку **Link** — тогда она будет подсвечиваться при выборе ноды.
