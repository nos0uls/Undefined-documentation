# Room Visual Editor (RVE)

Визуальный редактор комнат для расстановки актёров и рисования путей поверх скриншота игровой локации.

## Обзор

*Room Visual Editor* (RVE) открывается из главного окна Undefscene и показывает фон выбранной комнаты. RVE нужен для двух задач:

- Расставить актёров по координатам комнаты и импортировать их позиции в ноды `Actor Create`.
- Нарисовать траекторию движения и импортировать точки в ноду `Follow Path`.

Окно работает независимо от основного редактора — оно видно в Alt+Tab и остаётся поверх других приложений, пока не закрыто.

## Как открыть RVE

1. Подключите проект GameMaker через **File → Open Project (.yyp)** — без проекта список комнат и скриншотов будет пуст.
2. Откройте сцену или создайте новую.
3. Выберите в меню **View → Visual Editing** или нажмите кнопку **Визуальный редактор** на панели инструментов.
4. В открывшемся окне выберите комнату в выпадающем списке **Комната**.

Если для комнаты есть скриншоты, редактор загрузит их автоматически. При отсутствии скриншотов отобразится сообщение *«Нет комнат со скриншотами»*.

## Расстановка актёров

1. На панели **Актёры** выберите актёра из списка или укажите вручную.
2. Нажмите **Разместить актёра** — курсор перейдёт в режим размещения.
3. Кликните по фону в точке, где должен стоять персонаж.
4. Повторите для всех нужных позиций.
5. Нажмите **Импорт актёров** — координаты попадут в параметры `x`/`y` выбранных нод `Actor Create`.

!!! tip "Режим выбора"
    Чтобы передвинуть уже размещённого актёра, переключитесь в режим **Выбор** и перетащите маркер.

## Рисование путей

1. Выберите инструмент **Карандаш** на панели **Путь**.
2. Кликайте по фону, чтобы добавлять точки траектории.
3. Для прямых линий удерживайте **Shift**.
4. Чтобы стереть точку, переключитесь на **Ластик** (горячая клавиша `G`).
5. Нажмите **Импорт пути** — точки сохранятся в поле `points` ноды `Follow Path`.

Инструменты пути:

| Кнопка | Действие |
|--------|----------|
| **Карандаш** | Добавить точку кликом (`B`) |
| **Ластик** | Удалить точку (`G`) |
| **Очистить путь** | Удалить все точки |
| **Отмена** | Убрать последнюю точку |
| **Импорт пути** | Записать точки в выбранную ноду (`Ctrl+E`) |

## Импорт координат

RVE работает в координатах игрового мира, поэтому импортированные значения можно использовать в нодах напрямую — без ручного пересчёта.

- **Импорт актёров** обновляет поля `x` и `y` нод `Actor Create`.
- **Импорт пути** обновляет массив `points` ноды `Follow Path`.

!!! note "Импорт требует выбранной ноды"
    Перед нажатием **Импорт** убедитесь, что в основном редакторе выделена нужная нода. Иначе редактор предложит создать новую.

## Клавиши и масштабирование

| Клавиша | Действие |
|---------|----------|
| `B` | Карандаш |
| `G` | Ластик |
| `Ctrl+E` | Импорт пути |
| `Shift` | Прямая линия при рисовании |
| Колесо мыши | Масштаб |
| Правая кнопка мыши | Перемещение камеры |
| **Приблизить / Отдалить** | Кнопки на панели |
| **По размеру** | Вписать комнату в окно |

Панель **Сетка тайлов** позволяет включить сетку, привязку к ней и смещение, если тайлы комнаты начинаются не с `(0, 0)`.

## Troubleshooting

!!! warning "Скриншот не загружается"
    Проверьте папку скриншотов в настройках (**Edit → Preferences → General → Screenshot Output Folder**). Если папка пустая, сделайте скриншоты в GameMaker или укажите путь к существующим.

!!! warning "Импорт актёров неактивен"
    Убедитесь, что размещён хотя бы один актёр и в основном редакторе выбрана нода `Actor Create` с подходящим ключом.

!!! warning "Путь не импортируется"
    Для импорта пути нужна выбранная нода `Follow Path`. Если выбрана другая нода, редактор предложит создать новую.
