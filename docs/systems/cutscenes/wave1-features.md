# Wave 1: Музыка, позиционирование и логика

Редактор катсцен содержит три группы нод: управление музыкой, относительное позиционирование актёров и условное ожидание. Восемь нод поддерживают цикл компиляция → JSON → обратная компиляция и зарегистрированы в фабрике GML-действий.

!!! note "Runtime"
    Музыкальные ноды выполняются мгновенно (не блокируют очередь катсцены). `move_relative` является блокирующим действием. `set_position_relative` применяет смещение в один кадр. `wait_until` генерирует `guard_global`, который управляет потоком через внутренний механизм runtime.

---

## Музыка

Пять нод категории `audio` для управления фоновой музыкой из графа катсцены. Все ноды неблокирующие и возвращают управление сразу после запуска.

### `play_music`

Запускает музыкальный трек с опциональным кроссфейдом. Если `fade` меньше или равен нулю, воспроизведение начинается немедленно.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `sound` | searchable | Имя аудио-ассета |
| `volume` | number (0..1) | Громкость трека |
| `fade` | number (сек) | Длительность `fade-in` |

### `stop_music`

Останавливает текущую музыку с опциональным `fade-out`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `fade` | number (сек) | Длительность затухания |

### `music_volume`

Изменяет громкость музыки с плавным переходом.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `volume` | number (0..1) | Целевая громкость |
| `fade` | number (сек) | Длительность перехода |

### `music_duck`

Приглушает музыку на заданный множитель.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `multiplier` | number (0..1) | Коэффициент громкости |
| `fade` | number (сек) | Длительность перехода к приглушённому уровню |

### `music_unduck`

Восстанавливает громкость музыки после предыдущего `music_duck`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `fade` | number (сек) | Длительность восстановления |

## Позиционирование

Две ноды категории `movement` для перемещения и установки позиции актёра относительно его текущих координат.

### `move_relative`

Перемещает актёра на смещение `(dx, dy)` от текущей позиции. Блокирует выполнение катсцены до достижения цели.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `target` | searchable | Ключ актёра или `player` |
| `dx` | number | Смещение по X |
| `dy` | number | Смещение по Y |
| `speed_px_sec` | number | Скорость в пикселях/сек |
| `collision` | select | Учитывать стены и препятствия (`true` / `false`) |

### `set_position_relative`

Мгновенно сдвигает актёра относительно текущей позиции. Не блокирует очередь.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `target` | searchable | Ключ актёра или `player` |
| `dx` | number | Смещение по X |
| `dy` | number | Смещение по Y |

## Логика

### `wait_until`

Приостанавливает сцену до тех пор, пока глобальная переменная не станет равна заданному значению. Является синтаксическим сахаром для `guard_global` с `if_false: 'wait_until_true'` и пустым массивом `actions`.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `condition_var` | text | Имя глобальной переменной (без `global.`) |
| `condition_equals` | text | Ожидаемое значение для сравнения |
| `timeout_seconds` | number | Максимальное время ожидания в секундах; `0` — бесконечное ожидание |

!!! tip "Валидация"
    При экспорте графа нода `play_music` требует заполненного поля `sound`. Для `wait_until` обязательно поле `condition_var`. Нулевое значение `timeout_seconds` вызывает предупреждение о потенциально бесконечном ожидании.
