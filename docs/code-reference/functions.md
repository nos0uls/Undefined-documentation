# Глобальные Функции (Global Functions)

Навигация по справочникам функций и скриптов проекта.

## Разделы

- [GML скрипты](./gml-scripts.md): основной справочник по `scr_*` функциям.
- [Система ввода](../systems/input.md): API для обработки клавиш.
- [Система взаимодействия](../systems/interaction.md): логика взаимодействия с миром.
- [Катсцены: API](../systems/cutscenes/api.md): команды `c_*` и `cutscene_*`.

## Типы функций

В проекте используются следующие типы глобальных вызовов:
- Helper-скрипты `scr_*`.
- Системные обертки для ввода и настроек.
- Рантайм-команды катсценного движка.
