# Управление (Controls)

Список горячих клавиш и команд управления.

## Основные клавиши

| Клавиша | Действие | Контекст |
|---------|----------|----------|
| **WASD / Стрелки** | Движение | Игровой процесс |
| **Shift** | Бег | Игровой процесс |
| **Enter / Z** | Подтверждение / взаимодействие | Игровой процесс, меню |
| **Q** | Полноэкранный режим (`borderless`) | В любой момент |
| **↑/↓ / W/S** | Навигация по меню | Меню |
| **Escape / X** | Назад / закрыть | Меню |
| **B** | Удалить сохранение | Меню сейвов |

## Debug-режим

Доступен при активном дебаг-режиме (`F12 × 5`).

| Клавиша | Действие |
|---------|----------|
| **F1** | Показать инфо о позиции и направлении |
| **F2** | Показать коллайдеры |
| **F3** | Показать хитбокс / маркер взаимодействия |
| **F4** | Перезагрузка игры |
| **F5** | Предыдущая комната |
| **F6** | Следующая комната |
| **F7** | Быстрое сохранение |
| **F8** | Ghost mode (движение сквозь стены) |
| **F9** | Дебаг-оверлей музыки |
| **F12 × 5** | Включить / выключить дебаг-режим |
